<h2>Descripción</h2>

<p>Este proyecto consiste en el desarrollo de una aplicación Android centrada principalmente en el <strong>descubrimiento de nuevo contenido audiovisual</strong>, complementado con recomendaciones personalizadas para mejorar la experiencia del usuario. Utilizando tecnologías modernas como Jetpack Compose para la interfaz de usuario y Firebase como backend, la app ayuda a los usuarios a explorar una amplia variedad de películas y series, adaptadas a sus gustos y preferencias.</p>

<p>La aplicación cuenta con una interfaz de usuario intuitiva y agradable, diseñada para ofrecer una experiencia fluida y moderna. Aprovechando las ventajas de Jetpack Compose, la navegación entre pantallas es sencilla y accesible. Además, el diseño se adapta eficientemente a diferentes tamaños de pantalla, proporcionando una experiencia consistente en dispositivos móviles y tablets.</p>

<p>La app está diseñada para permitir a los usuarios <strong>descubrir y explorar nuevas películas y series</strong> de forma cómoda y personal según sus gustos y preferencias, haciendo del descubrimiento de contenido el foco principal al tiempo que ofrece recomendaciones personalizadas.</p>


<h2>Tecnologías utilizadas</h2>

<ul>
  <li>Jetpack Compose para la interfaz de usuario.</li>
  <li>Firebase para almacenamiento en la nube y autenticación.</li>
  <li>Gemini AI para trivias y moderación de comentarios.</li>
  <li>API de TMDB para acceder a datos de películas y series.</li>
  <li>Kotlin para el desarrollo Android.</li>
  <li>Python para el servicio automatizado de actualización semanal de datos.</li>
</ul>


<h2>Principales características</h2>

<ul>
  <li>Explorar y descubrir películas y series en diversos géneros y categorías.</li>
  <li>Recomendaciones personalizadas basadas en preferencias del usuario.</li>
  <li>Interfaz moderna e intuitiva usando Jetpack Compose.</li>
  <li>Búsqueda avanzada por título y género gracias a la API de TMDB.</li>
  <li>Registro, inicio de sesión y recuperación de contraseña mediante Firebase Authentication.</li>
  <li>Edición de perfil con subida de foto de usuario.</li>
  <li>Selección de géneros favoritos para recomendaciones personalizadas.</li>
  <li>Listas personalizadas con películas recomendadas, series y próximos estrenos.</li>
  <li>Soporte para modo offline para navegar sin conexión.</li>
  <li>Minijuego de trivia sobre cine a través de Gemini AI.</li>
  <li>Moderación de comentarios usando IA para filtrar contenido inapropiado.</li>
  <li>Posibilidad de añadir películas y series a favoritos.</li>
  <li>UI adaptable a diferentes tamaños de pantalla.</li>
  <li>Actualización semanal automatizada del catálogo mediante un servicio en Python que sincroniza la base de datos Firestore con los últimos datos de TMDB.</li>
</ul>
